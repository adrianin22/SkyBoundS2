v1.99: Create: Cosmonautics joins the pack, the space addon for Create: Aeronautics, so you can build rockets and fly to orbit with Create machinery. It is installed on the server too. This update also fixes the client crash when opening the pause menu: FTB Chunks was saving the minimap while its worker thread was still adding regions, and pressing ESC could close the game. The pack now ships a patched FTB Chunks jar. Nothing else changes.
